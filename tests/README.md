# tests

Checks that run wherever the building happens - no Switch, no game, no disc.

They cover the sections that need only the standard library, which is where
correctness can be asserted rather than observed: `core`, `format` and `accel`.

```sh
cmake -S . -B build -G Ninja && cmake --build build && ctest --test-dir build
```

| Check | Asserts |
|---|---|
| `core_check` | typed guest memory reads and writes big-endian at the right offsets |
| `nw4r_lyt_check` | layout matrices match the original's arithmetic |
| `nw4r_lyt_animation_check` | the layout animation walk: every kind of target, the curves' exact values, a TPL bound and swapped in, calls out with their return addresses, each build's offsets |
| `sdk_mtx_check` | the matrix library, including its paired-single multiply order |
| `sdk_thp_check` | the video decoder against a known frame |
| `nand_sysconf_check` | SYSCONF, against a file the runtime itself wrote |
| `nand_mii_check` | the Mii database, against a file the runtime itself wrote |
| `nand_title_check` | tickets, TMDs and WADs of both kinds, built here and read back |
| `disc_check` | disc images: headers, the Wii's partitions and clusters, the file table, and a cipher supplied by the caller |
| `archive_yaz0_check` | Yaz0 expands correctly, and refuses the streams that would read or write past a buffer |
| `synthetic_translate` | [a game with no Nintendo code](synthetic) translates end to end (needs `dotnet`) |

`data/` holds the two reference files. They contain nothing Nintendo made: they
are the settings block and the empty Mii database a blank console would have,
generated by our own first-run code. The Mii database was written again
(2026-11-03) when the empty one became the Mii Channel's full 0xBE6C0 bytes with
its parade entries formatted; the old file predated that and the check had
been failing since.

Every check builds with its asserts on whatever the build type
(`-UNDEBUG`): a Release build compiled them out, and until 2026-11-03 every
assert-based check passed whatever the code did.
