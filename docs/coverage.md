# What libwii-nx covers

Generated by `tools/wiinx-coverage`, which reads a game's symbol map, groups
its functions into the libraries they came from, and counts how many the
library has taken over. With a run's network log it also shows what share of
the main thread each library took, so the gaps are ordered by what they cost
rather than by how many functions they have.

Every target so far was found by noticing it in a profile. This is the picture
that replaces that.

## Reading it

- **`rvl.gx` is nearly done** - 333 of 398 - because the console's graphics
  path had to work before anything ran at all. It is also the largest single
  share, which is the graphics command decode described in
  [performance](performance.md).
- **`nw4r.g3d` is untouched**: 641 functions, none native. Its two hottest
  functions are 14.9% and 12.6% of a race frame on their own, and they are the
  pair that builds the display lists the runtime then spends 12.6 ms decoding.
  This is the largest gap in the library by any measure.
- **`nw4r.snd` is 1 of 719**, and audio costs about 5 ms a frame, most of it in
  the game's own callback.
- **`egg` is Nintendo's game framework**, not the console: a game links what it
  uses, and replacing it helps only the games that link it.
- **`rvl.mtx` and `msl`** are the sections written most recently, and the ones
  a new native should be modelled on: small, whole, and bound in every game
  without a line of hand-written glue.

## What a gap costs to close

A library is worth taking whole rather than function by function - a native
costs a boundary crossing, and a section taken whole crosses it once. What
makes one cheap or expensive:

| | |
|---|---|
| cheap | the code is hand-written assembly, identical in every build (`rvl.mtx`), or its semantics are a standard (`msl`) |
| moderate | compiled C whose source a decompilation publishes, with layouts that differ per build (`nw4r.lyt`, `nw4r.snd`) |
| expensive | it calls back into the game through vtables or callbacks (`nw4r.g3d`'s draw path), so the boundary has to be crossed carefully or not at all |
